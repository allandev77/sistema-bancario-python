# Sistema Bancário em Python

Projeto introdutório de um caixa eletrônico executado no terminal.

## Funcionalidades

- Consulta do saldo inicial.
- Depósito de valores positivos.
- Saque com validação de saldo disponível.
- Validação de valores positivos.
- Menu interativo com opção para sair.

## Tecnologias

- Python 3
- Entrada e saída pelo terminal
- Estrutura de repetição `while`
- Estruturas condicionais `if`/`elif`/`else`

## Como executar

1. Instale o Python 3.
2. Abra o terminal nesta pasta.
3. Execute:

   ```bash
   python "Caixa eletronico.py"
   ```

O saldo inicial demonstrativo é de `1000.0` e existe apenas durante a execução do programa.
